2인 협업 게임 프로젝트

프로젝트 소개

1.44MB는 2인으로 진행 중인 협업 프로젝트입니다. 팀 내에서 프로그래밍을 담당하며 게임의 주요 기능과 시스템을 구현하고 있습니다.

담당 역할

  • 게임 시스템 구현
  • 플레이어 기능 개발
  • UI 기능 구현
  • 게임 로직 개발
  • 버그 수정 및 유지보수
  • 기능 테스트

사용 기술

Unity
C#
GitHub

프로젝트에서 배운 점

협업 프로젝트를 진행하며 기능 구현뿐만 아니라 팀원과의 의사소통, 일정 관리, 코드 공유의 중요성을 배울 수 있었습니다. 또한 다양한 게임 시스템을 직접 구현하며 Unity 개발 경험을 쌓고 있습니다.
