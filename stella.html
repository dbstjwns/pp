Stella

Unity 기반 게임 프로젝트

프로젝트 소개

Stella는 Unity를 활용하여 개발 중인 게임 프로젝트입니다. 프로젝트 초기에는 UI/UX 구현과 기능 제작을 담당하였으며, 현재는 메인 기획을 맡아 게임의 전체적인 방향성과 콘텐츠를 설계하고 있습니다.

담당 역할

  • UI / UX 구현
  • 게임 기능 제작
  • 메인 기획 담당
  • 콘텐츠 설계
  • 게임 시스템 기획
  • 프로젝트 방향성 관리

사용 기술

Unity
C#
GitHub

프로젝트에서 배운 점

개발뿐만 아니라 기획 업무를 수행하며 프로젝트를 전체적으로 바라보는 시각을 기를 수 있었습니다. UI/UX 설계와 게임 기획이 실제 플레이 경험에 얼마나 큰 영향을 미치는지 배울 수 있었습니다.
